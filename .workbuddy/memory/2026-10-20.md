## 00:55 去掉模拟数据（真 bug：available 在模块求值时就定死了）

**根因**：`gateway.ts` 的 store 是模块级 `create(...)`，`available: !!bridge()` 在**模块求值那一刻**求值；
而 `main.tsx` 的 import 顺序是 `App` 在 `./lib/desktop` 之前，App → pages → gateway 先求值，
此时 `installTauriBridge()` 还没跑 → 桌面端把自己当浏览器预览：
Providers 渲染 14 张带假延迟的 mock 卡片、Logs 渲染 6 条假日志，还要顶着「演示数据 · 未连接桌面网关」。
**这类错不抛异常，只是安静地显示错的东西。**

修法（三重保险）：
- `ipc.ts` 末尾自举 `installTauriBridge()`（谁 import 它谁就得到桥）
- `gateway.ts` 顶部 `import './ipc'`（显式副作用导入，保证桥先于 store 求值）
- `main.tsx` 第一行 `import './lib/ipc'`；`initGateway()` 里再 `setState({ available: !!gw })` 兜一次

**删干净**：
- 删除 `src/lib/data.ts`（providers / logs / catalogEvents / discoverSources / candidates / traffic24h / quotaWindows，后四个是死代码）
- Providers：删 `BrowserFallback` + `MockCard`，换 `NoGateway` 空态
- Logs：删 mockLogs；未连网关时整块空态，导出按钮在无数据时禁用
- `components/ui.tsx` 新增 `Empty`（标题 + 说明，不接受示例行）
- 产物核对：`dist` 里 `llama-3.3-70b` 只剩 Routing 的 placeholder，`RPD 1K`/`演示数据` 归零

**顺手把「假按钮」也清掉**（同一类问题：点了有反应，但其实什么都没做）：
- 检查更新 → 真的 `GET api.github.com/repos/HanoCode/Free-LLM-plus/releases/latest`，比版本、给下载链接

## 01:40 暂停开关从「假按钮」变成真闸

原状：顶栏「暂停」只改本地 zustand，toast 说「请求将返回 503」，实际什么都没发生。
- `State_.paused: AtomicBool`（内存态，重启即恢复，避免「上次暂停这次忘了开」）
- `axum::middleware::from_fn_with_state(pause_guard)`：只挡 **POST**；`/health` 与 `/v1/models` 必须继续 200，否则「暂停」看起来像进程死了
- `GwStatus.paused` + `gw_pause` 命令 + store `setPaused`；顶栏改成读 `status.paused`，未连网关时禁用
- 删掉 `store.ts` 里那对只在本地的 `paused/togglePaused`
- 新 e2e `tests/pause_e2e.rs`：用上游命中计数证明「暂停期间一次都没发给上游」，并验恢复后不重启即可用
